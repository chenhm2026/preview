香港出生孩子回港读书需要什么手续？

本文指导香港出生孩子回港读书的手续，帮助父母了解入学流程。

用途：指导香港出生孩子回港读书的手续

适用对象：在香港出生但目前在内地居住的孩子及其父母

更新日期：2026年6月

PART 01

用途

本文指导香港出生孩子回港读书的手续，帮助父母了解入学流程。

PART 02

一、入学资格

1.1 入学条件

条件 说明
香港出生 在香港出生
香港身份证 持有香港身份证
适龄 符合入学年龄

1.2 入学年龄

阶段 年龄 说明
幼稚园 3-6岁 3年
小学 6-12岁 6年
初中 12-15岁 3年
高中 15-18岁 3年
PART 03

二、入学流程

2.1 幼稚园入学

步骤 说明
1. 选择学校 根据需求选择幼稚园
2. 提交申请 向学校提交入学申请
3. 面试 参加学校面试
4. 录取 等待录取通知
5. 注册 办理注册手续

2.2 小学入学

步骤 说明
1. 选择学校 根据需求选择小学
2. 提交申请 向学校提交入学申请
3. 面试 参加学校面试
4. 录取 等待录取通知
5. 注册 办理注册手续

2.3 中学入学

步骤 说明
1. 选择学校 根据需求选择中学
2. 提交申请 向学校提交入学申请
3. 入学考试 参加入学考试
4. 录取 等待录取通知
5. 注册 办理注册手续
PART 04

三、所需文件

3.1 基本文件

文件 说明
出生证明 香港出生证明
香港身份证 孩子的香港身份证
回港证 如从内地回港
住址证明 香港住址证明
成绩单 内地学校成绩单

3.2 其他文件

文件 说明
疫苗纪录 疫苗接种纪录
健康证明 健康检查证明
推荐信 如有
PART 05

四、注意事项

  • •提前申请：提前了解学校申请时间，避免错过申请期
  • •准备文件：提前准备好所有所需文件
  • •语言准备：如孩子不懂粤语/英语，需提前准备
  • •适应期：孩子需要适应新的学习环境
  • •费用预算：了解学校费用，做好预算
