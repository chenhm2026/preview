f005 · 香港租房｜看房前要准备的文件清单

如果你第一次在香港租房，你大概率会被这个问题困住——"业主 / 中介要看我什么文件？我得准备齐才能去看房吗？"

香港的租房流程和内地不同——看房前业主 / 中介就要审你的"租房资格"。如果文件不齐，可能白跑一趟；如果文件有瑕疵，业主可能压你议价。

这篇帮你：5 分钟搞清楚"看房前要带哪 4 类文件"，避免现场卡壳。

看房前要带哪 4 类文件

类别 具体内容 谁必须
身份证明香港身份证 / 护照 / 港澳通行证所有人
收入 / 在职证明雇主信 / 粮单 / 税单在职人士
资金证明银行月结单 / 存款证明所有人
住址证明现居住地址的水电煤单 / 银行月结单已租房的人

4 类文件详解

A. 身份证明

核心要求：证明你是合法居民 / 合法入境者。

身份 用什么
香港永久居民香港永久居民身份证
香港非永久居民香港身份证 + 签证 / 入境标签
内地居民（短期）港澳通行证 + 有效签注
内地居民（长期）港澳通行证 + 签注 + 工作 / 学生签证

💡 很多人不知道：业主偏好"长期租客"——访客签（L 签）通常不接受，逗留签（D 签）要看具体时长。看房前先确认自己签证允许停留多久。

B. 收入 / 在职证明

核心要求：证明你付得起租金。惯例是"月入 ≥ 月租 × 2.5"（即租金占收入不超过 40%）。

文件类型 内容 哪里开
雇主信职位、入职日期、月薪、公司盖章公司 HR
粮单最近 3 个月薪金单公司财务 / 自己留底
税单（可选项）最近 1 年薪俸税评税税务局（IRD）
自雇 / 自由职业公司商业登记证 + 银行流水自己整理

特殊场景：

·刚到港没收入证明：可提供银行月结单（显示存款 ≥ 6 个月租金）+ 原雇主推荐信（如适用）

·学生签证：可提供父母担保信 + 父母收入证明 + 亲属关系公证

·自雇 / 创业：可提供公司商业登记证 + 公司银行流水 + 个人银行流水

·刚到港没税单：税单不是必须文件——新到港人士多数没有香港薪俸税评税，银行月结单 + 雇主信 + 粮单足够

雇主信怎么开：

·找公司 HR（人事部）

·内容包括：职位、入职日期、月薪、雇佣性质（永久 / 合同）

·需公司盖章 + HR 签字

·多数 HR 当天就能开

⚠️ 收入不够的常见后果：业主直接拒绝，或者要求加押金（三按而非两按一上）。看房前先评估自己的"收入/租金比"。

C. 资金证明

核心要求：证明你付得起第一笔大额支出（押金 + 印花税 + 中介费）。

文件类型 内容
银行月结单最近 1-3 个月，显示账户余额
存款证明银行开具的余额证明（部分银行收费）
投资账户结单股票 / 基金账户（部分业主接受）

惯例要求：账户余额 ≥ 6 个月租金总额（含押金 + 中介费 + 印花税）。

月租 15,000 的标准：

项目 数额
第一笔总支出（参考 预算表）约 53,000
6 个月租金90,000
建议账户余额≥ 100,000 港元

D. 住址证明

核心要求：证明你现在的居住地址（业主用来发通知 + 验证你不是"失踪人口"）。

文件类型 内容
水电煤单最近 1 期，显示现居住地址
银行月结单邮寄版（电子版通常不被接受）
手机月结单显示邮寄地址
雇主信部分接受（显示公司地址 + 员工住址）

特殊场景：

·刚到港没住址：可提供酒店 / 临时住所地址 + 雇主信

·与父母同住：可用父母住址的水电煤单 + 亲属关系公证

4 类身份的文件清单差异

不同身份的"看房前必带文件"略有差异。

A. 在职人士（工作签证）

·✅ 香港身份证 / 签证

·✅ 雇主信

·✅ 最近 3 个月粮单

·✅ 最近 1 个月银行月结单

·✅ 现居住地址证明

B. 学生（学生签证）

·✅ 香港身份证 / 学生签证

·✅ 学校录取信 / 在读证明

·✅ 父母担保信 + 父母收入证明

·✅ 父母银行月结单

·✅ 家庭住址证明

C. IIQE 考牌后赴港从业（参考 IIQE 赛道）

·✅ 港澳通行证 + 签注

·✅ IIQE 考试合格证书

·✅ 拟入职公司 offer letter（如果有）

·✅ 个人银行月结单（显示存款）

·⚠️ 特殊提醒：IIQE 考牌只是从业资格，实际赴港工作还需要工作签证。没工作签证 = 没法长期租约。

D. 跨境家庭

·✅ 双方身份证件

·✅ 一方雇主信 + 一方家庭住址证明

·✅ 双方银行月结单

·✅ 结婚证 / 亲属关系公证（如跨境学童）

·⚠️ 跨境家庭签要看具体安排（参考 跨境家庭口岸地段）

5 个常见误区

误区 1：以为文件可以"口头说"

❌ 错。业主 / 中介只看文件，不接受"我月薪 X 万"的承诺。没文件 = 没资格看房。

误区 2：以为学生签证不能租房

❌ 错。学生签证可以租房，但通常需要父母担保。签约前准备好父母文件，业主才会接受。

误区 3：以为访客签（L 签）可以签长租

❌ 错。访客签一般只能待 7-180 天，没法签 1 年长约。逗留签（D 签）要看具体时长和工作 / 学习状态。

误区 4：以为电子版文件可以

❌ 错。业主 / 中介通常只接受纸质版 / PDF（带盖章 / 银行章）。电子截图多数不被接受。

误区 5：以为自雇 / 自由职业没法通过审查

❌ 错。自雇人士可以提供商业登记证 + 公司银行流水 + 个人银行流水。关键是证明稳定收入，不是非要雇主信。

误区 6：以为没税单就不能租房

❌ 错。税单是"加分项"，不是"必须项"。新到港人士多数没有香港薪俸税评税，银行月结单 + 雇主信 + 粮单足够——业主 / 中介不会因为没税单拒签。

看房前最后清单

带齐这 5 件，看房不卡壳：

身份证 / 签证（原件 + 复印件 2 份）

雇主信 / 收入证明

银行月结单（最近 1-3 个月）

现居住地址证明

提前列出 3-5 个想问业主的问题

雇主信应包含字段

·公司抬头（盖章）

·员工姓名 + 身份证号

·职位 + 部门

·入职日期

·月薪 + 雇佣性质（永久 / 合同 / 试用）

·公司 HR 签字 + 联系方式

·开具日期（3 个月内有效）

💡 没有正式雇主信怎么办：自由职业 / 自雇人士可写自雇声明——含个人姓名、收入来源、客户列表、银行月结单。

学生签证父母担保信应包含字段

·担保人姓名 + 与申请人关系

·担保人身份证号 + 联系方式

·担保金额 + 担保期限

·担保人签字 + 公证（部分业主要求律师公证）

·担保人收入证明（雇主信 + 银行月结单）

💡 没父母能担保怎么办：可以找香港本地的朋友 / 同事做担保人——但需对方愿意 + 收入证明齐全。

官方入口汇总

在职人士的收入 / 税单通过 税务局 申请；商业登记证查询走 公司注册处；学生签证相关证明参考 入境事务处。

⚠️ 本篇仅作信息整理。业主对文件的具体要求可能不同，看房前先电话 / 微信问中介要什么文件，避免白跑。
