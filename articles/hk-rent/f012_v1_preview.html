f012 · 香港租房｜实地看房 Checklist（白天 + 晚上各看一次）

如果你第一次在香港租房，你大概率会觉得"看房就是走一圈"。这是错的。

看房是决定你未来 1-2 年生活质量的关键步骤。只看一次 = 看不到 70% 的坑——治安、噪音、邻居、维修、卫生、采光、漏水，白天看 vs 晚上看差异巨大。

这篇帮你：5 分钟搞清楚"实地看房要看什么"+"白天 + 晚上各看一次"的差异。

为什么必须看两次？

看房时间 重点 看不到的
白天（10-18 点）采光、噪音、水压、邻居治安、夜间噪音、路灯
晚上（19-22 点）治安、路灯、邻居、夜间噪音采光、水压

核心提示：只白天看 = 60% 信息；只晚上看 = 50% 信息；都看 = 90% 信息。

💡 很多人不知道：白天看着很安静的房子，晚上可能楼下是酒吧 / 卡拉 OK；白天看着有采光的房子，晚上可能路灯都没开。必须看两次。

白天看房 20 项 Checklist

A. 房子本身（10 项）

采光：客厅 + 卧室白天是否明亮？哪个朝向？

通风：开窗后空气流通吗？有无异味（霉味 / 油烟 / 排水）？

水压：开水龙头 + 花洒，水压够吗？同时开 2 个龙头会不会变小？

噪音：关窗后，室内的噪音分贝（马路 / 邻居 / 电梯）

墙面：是否有水渍 / 发霉 / 裂纹？

地板：是否有翘起 / 凹陷 / 划痕？

门窗：开关是否顺畅？密封是否好？

家具家电：空调、热水器、洗衣机、冰箱是否正常？

插座数量：每个房间至少 2-3 个？

WiFi 信号：手机信号 + WiFi 信号是否够？

B. 大厦与配套（5 项）

电梯：有几部？高峰期要等多久？

大堂管理：有无 24 小时保安 / 闭路电视？

垃圾处理：垃圾房在哪里？是否卫生？

邮件 / 包裹：是否有专门的邮件室？

消防通道：是否有逃生指示？消防设施是否齐全？

C. 周边环境（5 项）

街市 / 超市：步行 10 分钟内有吗？

餐厅 / 饮食：附近有什么餐厅？

公共交通：最近的巴士站 / 港铁站多远？

医院 / 学校：最近的急诊医院多远？

公园 / 运动：附近有公园 / 体育馆吗？

晚上看房 10 项 Checklist

A. 治安与照明（4 项）

路灯：大厦周围路灯是否亮？

治安：晚上 9-10 点在附近走一圈，是否安全？

监控摄像头：大厦入口 / 电梯 / 走廊有无闭路电视？

保安值班：是否有 24 小时保安？

B. 夜间噪音（3 项）

马路噪音：关窗后，是否能听到马路声？

邻居噪音：晚上 9-10 点是否能听到邻居的电视 / 音乐？

楼下噪音：是否有酒吧 / 卡拉 OK / 餐厅？

C. 邻居与社区（3 项）

邻居情况：进出大厦的邻居是什么人？（白天 vs 晚上差异大）

公共区域：走廊 / 大堂 / 电梯是否整洁？

特殊气味：晚上是否闻到异味（垃圾 / 排水 / 油烟）？

5 个必做测试动作

测试 1：开水龙头 + 热水器

·同时开 2 个水龙头，看水压变化

·开热水器（如适用），看加热速度 + 是否漏气

·问供水时段——老唐楼 / 村屋因水泵系统老化，夜间水压可能偏低（晚上 11 点 - 早上 6 点）——直接问业主 / 中介："几点到几点有水？"

💡 部分老旧大厦因水泵系统老化或楼宇供水设计问题，夜间水压可能偏低——新人入住后才发现"晚上洗澡没水"是高频投诉。看房时直接问业主/中介"几点到几点有水"最稳。

测试 2：开所有电器

·同时开空调 + 热水器 + 微波炉，看是否跳闸

·香港老房子电路可能老化，跳闸是常见问题

测试 3：拍照存档

·每个房间 + 墙面 + 地板 + 家具 + 家电都要拍照

·特别记录已有损坏——避免退租时被扣押金

·家具家电拍序列号——空调 / 热水器 / 洗衣机 / 冰箱的型号 + 序列号——保修 + 维权的关键证据

测试 4：检查 WiFi / 手机信号

·每个房间都试一下——香港有些大厦信号死角多

·WiFi 路由器放在哪？信号是否覆盖所有房间？

测试 5：看大厦公告板

·有无装修通知 / 维修计划 / 业主立案法团公告

·未来 1-2 年是否有大装修 / 外墙翻新 / 加装电梯？

⚠️ 看完不拍照 = 退租时业主说损坏全是你弄的——押金被扣几千港元。拍照是最便宜的"保险"。

5 类房子重点关注

A. 唐楼（无电梯）

·噪音：楼下马路 + 楼上邻居

·采光：对面楼距离近，可能挡光

·维修：楼龄大，水管 / 电路老化

·治安：无保安，晚上安全靠自己

B. 洋楼（有电梯但楼龄大）

·电梯：单梯可能不够用（高峰期等很久）

·管理费：洋楼管理费可能高

·维修：定期大维修（外墙 / 水管），可能加业主分摊

C. 村屋（新界）

·配套：可能没有 24 小时便利店

·交通：巴士班次密度低（晚上可能 1 小时一班）

·安全：偏僻地区，治安靠自己

·地契：参考 村屋地契

D. 劏房（分間單位）

·消防：逃生通道是否合规？

·水电：是否独立水电表？

·改建痕迹：墙面 / 天花板是否有不规范改建？

·⚠️ 劏房风险最高，签约前务必找专业人士验楼

E. 居屋（已补地价）

·管理规则：居屋屋苑有自己的管理规则（如不可养宠物）

·维修：居屋维修要找屋苑管理处

·转售限制：未来转租仍要补地价

⚠️ 看房不仔细，入住后发现隔音差 / 水压小 / 治安差 / 维修没人理——1-2 年生活质量极差。看房 1 次 = 节省未来 1-2 年的麻烦。

5 个常见误区

误区 1：以为"看一次就够了"

❌ 错。白天 + 晚上各看一次 = 看到 90% 问题。只看一次 = 至少漏 30% 信息。

误区 2：以为"照片漂亮就行房"

❌ 错。照片只反映白天的状态——晚上治安 / 噪音 / 照明照片里看不到。

误区 3：以为"中介带看就够了"

❌ 不一定。中介可能隐瞒问题（特别是业主要求不让你看到）。自己独立走 1 圈很重要。

误区 4：以为"签了约就不能反悔"

❌ 不一定。香港租约没有法定冷静期，签约后即受法律约束。但签约前仔细审阅条款、发现不合理条款及时协商，比签约后维权更有效。

误区 5：以为"看房免费就多看几家"

❌ 不一定。看房时间宝贵——中介带你看 1 家平均 30-60 分钟。看 5-10 家足够，过多反而浪费时间。

看房后的 3 个动作

看完房不要当场决定。24 小时内做这 3 件事：

1. 和家人讨论——是不是真的满意？

2. 再看一次（如果决定签）——确认状态没变

3. 谈判 + 签约准备——参考 租约条款解读

24 小时便利店距离

步行 5-10 分钟内是合理——香港便利店密度高，但要确认晚 12 点后还有。

邻居素质判断（看房时直接测试）

·隔音测试：在房子里大声说话 / 放音乐 30 秒——楼下 / 隔壁能不能听到？

·门口观察：看邻居门口——堆物 / 烟味 / 鞋柜乱放 = 邻居可能不爱整洁

·门口鞋柜：香港很多大厦门口放鞋柜——观察邻居的鞋柜风格（运动鞋多 = 可能有小孩；拖鞋多 = 可能是长者；鞋多 = 住人多）

·电梯观察：等电梯时看邻居——年龄 / 职业 / 行为

·公共走廊：气味 / 整洁度——反映大厦管理质量
