f017 · 香港租房｜入住验房清单（水电煤 / 家具 / 墙面拍照存档）

如果你第一次在香港租房，你大概率会跳过"入住验房"这一步——这是错的。

入住验房 = 给房子拍"现状照"。退租时业主会用"现状"vs"你入住后"对比——没拍照 = 几千元押金被扣。

这篇帮你：5 分钟搞清楚"入住时要检查什么"+"怎么拍照才算有效证据"。

为什么要拍照存档

核心逻辑：

·入住时——房子什么状态？

·退租时——业主说"你弄坏的"vs 你说"入住时就坏了"

·谁有证据——谁就赢

真实案例：

没拍照的后果 有拍照的后果
业主说墙面有 5 处划痕，扣 3,000 港元押金照片显示入住时就有，业主无依据扣
业主说马桶漏水是你弄的照片 + 视频显示入住时就漏水
业主说地板有 3 处凹陷照片显示入住时就有凹陷

⚠️ **：没拍照 → 业主任意扣押金 → 1-2 千港元蒸发。拍照 30 分钟 = 省几千港元**。

60 项验房 Checklist

A. 大门与玄关（8 项）

门锁：开关是否顺畅？钥匙有几把？

门框：有无刮痕 / 凹痕？

门吸 / 闭门器：是否正常？

玄关灯：是否亮？

玄关柜 / 鞋柜：内部是否干净？有无损坏？

地砖：有无破损？

门槛：有无损坏？

防盗链 / 猫眼：是否正常？

B. 客厅（12 项）

墙面：有无水渍 / 发霉 / 裂纹 / 钉孔？

地板：有无翘起 / 凹陷 / 划痕？

天花板：有无水渍 / 发霉？

空调：能否制冷 / 制热？滤网是否干净？

灯：所有灯是否亮？

插座：所有插座是否有电？

窗户：开关是否顺畅？密封是否好？

窗帘：是否完好？

电视柜 / 沙发：是否完好（如有）？

餐桌 / 餐椅：是否完好（如有）？

挂钟 / 装饰：是否完好（如有）？

网络 / 电话接口：是否可用？

C. 卧室（10 项 × 每个房间）

墙面：有无水渍 / 发霉 / 裂纹 / 钉孔？

地板：有无翘起 / 凹陷 / 划痕？

天花板：有无水渍 / 发霉？

空调：能否制冷 / 制热？滤网是否干净？

灯：所有灯是否亮？

插座：所有插座是否有电？

窗户：开关是否顺畅？密封是否好？

窗帘：是否完好？

床 / 床垫：是否完好（如有）？

衣柜：内部是否干净？门是否正常开关？

D. 厨房（10 项）

灶台：点火是否正常？火力如何？

抽油烟机：吸力是否够？是否清洗过？

冰箱：制冷是否正常（如有）？

微波炉：是否正常（如有）？

烤箱：是否正常（如有）？

洗碗槽：有无堵塞？水龙头是否正常？

橱柜：内部是否干净？门是否正常？

地砖：有无破损？防水是否好？

墙面：有无油渍 / 水渍？

水管：有无漏水？

E. 卫生间（10 项）

马桶：冲水是否正常？水位是否够？

马桶盖：是否完好？

花洒：出水是否正常？水压够吗？

洗手盆：下水是否顺畅？水龙头是否正常？

镜子：是否完好？

浴缸 / 淋浴间：防水是否好？有无漏水？

地砖：有无破损？防滑性？

墙面：有无发霉 / 水渍？

通风扇：是否正常？

热水器：是否正常？煤气 / 电热？

F. 阳台 / 天台（5 项）

地砖：有无破损？

栏杆：是否稳固？

晾衣架：是否完好（如有）？

排水口：有无堵塞？

天台防水：是否有渗漏（如适用）？

G. 水电煤读数（5 项）

水表读数：拍照记录

电表读数：拍照记录

煤气表读数：拍照记录（如适用）

电费账户过户：联系电力公司（中电 / 港灯）

水费账户过户：联系水务署

煤气账户过户：联系煤气公司（如适用）

测试 6：核对入住前水电煤基准

·拍照记录水电煤读数（入住当天）

·保留入住前最后 1 期账单——业主给的（如果给）

·入住后第 1 期账单出来后核对——有些房子电表读数造假（前任租客买通业主）——账单异常立即联系业主 / 中介

⚠️ 第 1 期账单核对是"事后保险"——入住当天拍照是"事前证据"。两者结合才能防电表读数造假。

拍照的 6 个技巧

技巧 1：每个房间至少 8 张

·全景（房间全貌）

·4 个角落（每个角 1 张）

·天花板

·地板

·细节（墙面 / 插座 / 窗户）

技巧 2：拍有损坏的地方

·特写——让损坏看得清

·带参照物（硬币 / 手指）显示比例

·多次拍摄——不同角度

技巧 3：拍日期

·手机自带时间戳——照片自动带日期

·不要关掉时间戳

·不要修改照片（原始证据）

技巧 4：录视频

·每个房间 30 秒视频——从门口扫到窗户

·拍水电表读数——视频更清楚

技巧 5：建一个"入住档案"文件夹

·照片 + 视频 + 文档（租约 / 业主身份证复印件）

·云端备份（Google Drive / iCloud）

·本地备份（U 盘 / 硬盘）

技巧 6：发给业主确认

·拍照当天发给业主微信 / 邮件

·业主回复"收到"——确认接收

·避免日后扯皮——业主不能说你拍照不真实

⚠️ **：照片没发给业主 → 业主说"照片是你拍的假证据"。发给业主确认 = 法律意义上的"双方确认"**。

水电煤过户的 4 个步骤

第 1 步：联系公用事业公司

公用事业 公司 联系
电中电 / 港灯网上申请过户
水水务署网上 / 电话
煤气港燈 / 中華煤氣网上 / 电话
网络各 ISP网上 / 电话

第 2 步：准备文件

·租约

·业主身份证复印件

·租客身份证

·押金收据

第 3 步：提交申请

·网上提交最方便

·部分需业主配合签字

第 4 步：确认过户成功

·收到新账户确认——账户是你的名字

·下次账单——开始寄给你

⚠️ **：水电煤没过户 → 业主的账户在用——你付了钱但业主收。过户是入住第一步**。

⚠️ 业主不配合过户怎么办：少数业主不愿配合（怕租客欠费影响业主）——白纸黑字约定（在租约或独立协议中）"X 天内配合水电煤过户，否则承担 X 港元 / 天的违约金"。法律上水电煤账户应过户给实际使用人。

与业主签「入住确认书」

核心建议：和业主一起签一份"入住确认书"——记录：

·入住日期

·水电煤读数

·家具家电清单

·双方确认的损坏（拍照 + 文字描述）

⚠️ **：没签入住确认书 → 退租时业主说"你没报告 = 你弄坏的"。入住确认书是法律文件**。

5 个常见误区

误区 1：以为"看房时看过了就行"

❌ 错。看房 → 入住有时间差——期间可能业主修过 / 损坏。入住时还要再验一遍。

误区 2：以为"拍照不发给业主也行"

❌ 不一定。发给业主 = 双方确认——避免日后扯皮。没发 = 法律效力较弱。

误区 3：以为"水电煤自动过户"

❌ 错。必须手动申请——业主 / 租客都要签字。没过户 = 用业主账户。

误区 4：以为"家具家电不拍照也行"

❌ 不一定。家具家电损坏也是纠纷高发区——拍照 + 列入清单。

误区 5：以为"退租时再说"

❌ 错。退租时业主只相信"当时"的证据——你入住时的照片 + 入住确认书才是关键。
