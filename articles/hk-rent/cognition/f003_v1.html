f003 · 香港租房｜4 类房源对比：私楼 / 居屋 / 公屋 / 村屋

如果你刚来香港或第一次自己租房，你大概率会被这个问题困住——"中介挂出来的都叫私楼，但我怎么知道有没有更便宜的选项？"

香港的租房市场不是只有"业主直租+中介放盘"两种。政府资源（公屋、居屋）+ 郊外选项（村屋）加起来占了相当一部分存量。如果只看中介放盘，你可能多花 30%-50% 的钱。

这篇帮你：用 5 分钟分清 4 类房源，搞清楚自己适合哪一类。

先问自己 2 个问题

问题 1：你现在最在意的是"省时间"还是"省钱"？

·省时间（急入住 / 工作已定 / 学校网已定）→ 跳过公屋，直接看私楼 / 村屋

·省钱（愿意等 / 收入符合政府限额）→ 先看公屋 / 居屋

问题 2：你的签证 / 身份能申请政府房屋吗？

·✅ 能（永居 / 单程证 / 受养人签证）→ 公屋 / 居屋可申请

·❌ 不能（学生签证 / 优才刚批未激活 / 工作签未满 7 年）→ 只能看私楼 / 村屋

很多人不知道公屋 / 居屋的存在，或以为"政府房屋 = 穷人住的"——其实公屋租金约为市值 1/3，只要收入及资产符合限额就能申请。先查自己符不符合资格，比直接看私楼更省时间。

4 类房源全景图

类别 一句话定位 价格定位 谁能租
私楼市场主流，业主自由放租中高几乎所有人
居屋政府资助出售的房子，已补地价后可租中几乎所有人（要"补地价后"的房子）
公屋政府出租屋，租金远低于市价低必须通过资格审核（轮候册）
村屋新界乡郊的低密度住宅视地段几乎所有人

私楼：90% 的人会先看这一类

业主拥有完整业权的私人住宅，可在公开市场自由放租。来源包括地产中介挂牌、业主自放、网上平台。

找中介看房、在 28Hse / Spacious 等平台看到的房子，绝大多数都是私楼。优点是房源多、议价灵活、签约快；缺点是价格市场化、租约条款要看清。

适合你吗：

·✅ 第一次到港、不知道未来住多久

·✅ 收入证明齐全、想快点安顿

·✅ 需要特定地段（学校网 / 医院 / 通勤口岸）

不适合你吗：

·❌ 预算特别紧、愿意等政府资源（应看公屋 / 居屋）

·❌ 完全不愿签长约（应看短租 / 服务式公寓，不在本赛道范围）

⚠️ 如果你不问清楚租约条款直接签，押金被多扣 / 中途被加租 / 维修被甩锅是 3 个最常见的坑。签约前务必看 租约条款解读。

居屋：很多人不知道可以租

香港房屋委员会或香港房屋协会资助出售的房屋，业主以低于市价买入，但要受转让限制。未补地价只能在居屋第二市场卖给绿表 / 白表买家，不能在公开市场放租；已补地价后可自由买卖 + 放租。

居屋 = "绿表 / 白表那种"，你可能以为"我没资格买"。但这里讲的是租房——只要房子已经补了地价，任何人都可以租。问题是居屋屋苑有自己的管理规则，租前要问清楚。

关键限制（很多人踩的坑）：

·🚫 未补地价的房子在公开市场租不到——违规转租会被房委会追究

·✅ 已补地价的房子补缴地价差额后，可自由放租

·📋 居屋第二市场的转租限制更严

·✅ 未补地价但可分租亲属——业主自行居住时，可以分租部分房间给非业主亲属——这是常见例外，新人最常误解

关键概念解释：

·"补地价" = 居屋以低于市价卖给业主（政府补贴），业主转售或出租前要补缴差价给政府——所以叫"补地价"

·"居屋第二市场" = 居屋业主之间的私下买卖市场（不进入公开市场）——买家也必须是绿表 / 白表人士

适合你吗：

·✅ 不打算买居屋，但接受居屋户型 / 屋苑管理

·❌ 找"未补地价便宜房"——这种房子不存在，别被骗

公屋：资格门槛高，但能省一大笔钱

香港房屋委员会出租的公共房屋，租金远低于市价，受条例保护。一般申请需年满 18 岁、香港居民、入息及资产限额内；轮候册制度下，符合资格不代表马上有房。

公屋不是"穷人专属"——只要你收入及资产符合政府公布的限额（每年调整），就能申请。租金约为市值 1/3 到 1/4。问题是轮候时间长。

关键数据（以房委会最新公布为准，数字会变）：

·一般申请者平均轮候时间约 5-6 年（数字持续变动）

·长者一人申请者约 3-4 年（优先编配）

·非长者一人申请者约 6-7 年（最久）

·租金约为市值 1/3 至 1/4

💡 单人申请的港漂：轮候时间比家庭长 1-2 年——要先评估值不值得等。

适合你吗：

·✅ 收入及资产符合限额（先查官方限额表）

·✅ 不急入住、愿意等

·✅ 长期居港（永居 / 单程证）

不适合你吗：

·❌ 短期居港（留学 / 工作前 2-3 年）——轮候时间太长，等不起

·❌ 想自由选地段——公屋由房委会按区域统一编配

⚠️ 公屋申请被拒最常见的原因是收入或资产超出限额。但很多人不知道的是单身 vs 家庭限额不同，深港两地资产合并计算。申请前务必看官方限额表，别自己估。

村屋：郊外选项，有车 / 养宠的人会喜欢

新界乡郊地区的低密度私人住宅，多为 3 层高独立屋。地契年期分两类：1898 年 5 月 25 日前的旧批约 vs 之后的新批约，到期日不同。签约前建议找专业人士确认地契年期。

村屋 = "没电梯、配套少、但便宜 + 空间大 + 宠物友好"。如果你接受郊外生活、有车、不依赖公共交通，村屋可能是性价比最高的选择。

特点：

·✅ 价格通常比市区私楼低 20-40%

·✅ 空间大、宠物友好、邻里关系松散

·⚠️ 配套少（可能没电梯、商场、24 小时便利店）

·⚠️ 通勤时间长（远离地铁 / 巴士总站）

·⚠️ 地契年期差异大——签约前务必确认

适合你吗：

·✅ 接受郊外生活 / 有车 / 养宠物

·✅ 预算有限但不愿住偏远市区

·✅ 跨境家庭（有车经口岸往返）

不适合你吗：

·❌ 完全依赖公共交通

·❌ 需要 24 小时医疗 / 学校配套

·❌ 对地契年期不熟悉

⚠️ 村屋最常见的坑是地契年期剩多少年不知道——如果剩余年期短，可能影响你之后续约、转租、孩子入学。签约前花几百块找专业人士做地契查册，省掉后面的麻烦。

怎么选

不用背规则，跟着树走。

你预算有限 + 有永居 / 单程证？

├── 是 → 公屋（接受轮候时间）

└── 否 ↓

你要特定地段（学校网 / 医院 / 口岸）？

├── 是 → 私楼（公开市场）

└── 否 ↓

你想要较低价格 + 接受郊外 + 有车？

├── 是 → 村屋（看清地契）

└── 否 → 私楼

5 个常见误区

误区 1：以为公屋只有低收入才能申请

❌ 错。公屋按"入息及资产限额"审批，单身 vs 家庭限额不同。一个 3 口之家即使月入 4 万港元也可能符合。

误区 2：以为居屋未补地价可以租

❌ 错。未补地价只能在居屋第二市场卖给绿表 / 白表买家，不能在公开市场放租。看到"未补地价便宜出租"——99% 是骗。

误区 3：以为村屋不用看地契

❌ 错。村屋地契年期差异巨大，剩余年期影响续约、转租、入学。签约前不查，后面可能续不了约。

误区 4：以为私楼一定有电梯 + 24 小时配套

❌ 错。私楼包括唐楼（无电梯）、洋楼（有电梯但楼龄大）、村屋（郊外）。看房前问清楚楼龄和配套。

误区 5：以为"政府房屋 = 慢 = 等不起"就不申请

❌ 错。公屋 / 居屋申请是"挂着就行"——你完全可以先申请，同时继续找私楼。轮候期间租房住不影响。等编配到了再决定要不要搬。

官方入口汇总

公屋与居屋申请，先看 香港房屋委员会 的资格与轮候册；夹心阶层住屋参考 香港房屋协会；村屋签约前查 地政总署 的地契资料。判断市场报价可以查 差饷物业估价署 的季度报告；找房时想确认大厦与业主立案法团信息，看 民政事务总署。

⚠️ 本篇仅作信息整理，不构成租约建议。公屋轮候时间、居屋申请资格、村屋地契年期均会变动，请以官方最新公布为准。
