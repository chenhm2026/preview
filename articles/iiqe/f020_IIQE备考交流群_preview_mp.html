港险考牌-社群｜IIQE 备考交流群入口与规则

港通+ IIQE 备考交流群提供：

定位：社群入口（闭环）

上线 Phase：Phase 3

用途：让通过 IIQE 内容感兴趣的人能加入备考交流群，形成"内容 → 社群 → 反哺"闭环

PART 01

适用对象

  • •正在备考或准备考 IIQE 的人
  • •想找同期考生交流的人
  • •想获取 IIQE 备考资料和模拟题的人
  • •想了解不同平台 / 公司 / 团队的人

不适用：完全不打算考 IIQE 的人，本群是 IIQE 备考专属。

PART 02

一、群的价值

港通+ IIQE 备考交流群提供：

1. 资料分享

  • •自制笔记互享
  • •PEAK 大纲解读
  • •学习小组合作
  • •模拟题互出互答

2. 同伴交流

  • •同期考生进度同步
  • •备考节奏讨论
  • •互相提醒考试日期
  • •互相监督学习

3. 高频问题沉淀

  • •群内高频问题每周整理
  • •整理成公众号文章反哺内容
  • •让 IIQE 内容持续更新

4. 平台 / 公司 / 团队观察经验分享

  • •备考期开始观察不同平台、公司、团队
  • •分享观察心得
  • •互相提醒红旗信号
PART 03

二、群规则

规则 1：禁止产品推介

  • •禁止任何保险产品推介
  • •禁止"我这里有更好的方案"
  • •禁止推广任何具体公司或团队

规则 2：禁止未授权资料传播

  • •官方公开资料（PEAK 大纲、IA 法规）：可以发原链接
  • •自制资料：可以分享
  • •付费课程 / 题库 / "内部资料"：禁止传播

规则 3：禁止保过 / 押题宣传

  • •"保过 IIQE" → 禁止
  • •"押题命中率 X%" → 禁止
  • •"包通过" → 禁止

规则 4：尊重不同选择

  • •准备做代理人？OK
  • •准备做经纪人？OK
  • •暂不入行？OK
  • •暂不考 IIQE？OK
  • •不评判他人的职业选择

规则 5：医疗紧急情况联系专业机构

  • •医疗问题不替代医生
  • •紧急情况联系医院 / 救护车
PART 04

三、群内阶段标签（按需标注）

进群后可在昵称后加上阶段标签：

  • •[了解中]
  • •[准备报名]
  • •[备考中-Paper I]
  • •[备考中-Paper II]
  • •[备考中-Paper III]
  • •[已通过]
  • •[入行中]

方便群内同伴了解彼此进度，互相支持。

PART 05

四、群内高频话题

  • •IIQE 考试报名经验
  • •各卷备考资料分享
  • •模拟题出题与互答
  • •考前冲刺经验
  • •考后路径选择讨论
  • •PE-CPD 课程推荐
  • •平台 / 公司 / 团队观察分享
  • •行业认知交流
PART 06

五、群运营要点

  • •维护群秩序
  • •整理高频问题为文章
  • •提供官方资料索引
  • •回答通用问题（不涉及具体公司 / 团队）
PART 07

六、如何入群

方法 1：飞书 DM 内申请

  • •通过港通+ 飞书 DM 发送"加入 IIQE 群"
  • •管理员会发送入群方式

方法 2：港通+ 公众号菜单

  • •公众号底部菜单 → 实用工具 → 加入社群
  • •选择 IIQE 备考交流群
  • •按提示入群

方法 3：港通+ 关键词回复

  • •公众号内回复关键词 "IIQE"
  • •自动获取入群方式
PART 08

七、退出与申诉

退群

  • •任何时候自由退群
  • •不需要理由

申诉

  • •如被误踢，可在港通+ 飞书 DM 申诉
  • •24 小时内响应
PART 09

八、群与其他社群的区别

维度 IIQE 备考交流群 一般备考群 / 培训群
立场 中立（不偏向任何公司 / 团队） 可能偏向特定公司
资料 公开资料 + 自制 可能含付费课程
运营 港通+ 维护 培训机构或个人
商业化 无 可能有
长期价值 持续反哺公众号内容 培训结束群解散
